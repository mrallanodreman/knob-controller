# KNOBController

Software libre de Edge Marketing Agency (EMA) — mapea el knob giratorio del
teclado MEETION a scroll o volumen, y el clic del knob a la tecla que
elijas (Enter, Esc, Tab, Espacio, Reproducir/Pausa o Silencio nativo).

App nativa de escritorio con interfaz visual en vivo — la perilla en
pantalla gira cuando giras el knob físico.

📍 Hoy: Linux (evdev + /dev/uinput + GTK3). Windows y macOS necesitan un
backend nativo distinto (HID en vez de evdev) — ver `native-app/README.md`.
